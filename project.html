OVERVIEW

Move your mouse just by concentrating. A low-cost EEG headband, Python signal filtering and a quick calibration step.

About this project

Last year I saw a demo of someone controlling their computer through concentration alone and wanted to build my own. It took me months to piece together — so here’s the blueprint I wish I’d had. The headset streams brainwave data over Bluetooth, a Python script filters out noise, and a simple threshold turns focus into cursor movement.

Build steps

6 steps
  1. 01

    Pair the headset

    Charge the headset, turn on Bluetooth pairing mode and connect it to your laptop. Check that the signal-quality light turns solid.

    step photo
  2. 02

    Install the Python libraries

    Create a virtual environment and install the libraries listed above. Run the test script to confirm data is streaming.

  3. 03

    Filter the raw signal

    Apply a band-pass filter to keep the frequency range linked to focus, then average it over a short window to smooth out spikes.

    step photo
  4. 04

    Calibrate your baseline

    Record 30 seconds relaxed and 30 seconds concentrating. The script saves a personal threshold halfway between the two.

  5. 05

    Map focus to the cursor

    When the focus value stays above your threshold, move the cursor in the current direction. Blink twice to switch direction.

  6. 06

    Tune and test

    Adjust the threshold and smoothing window until movement feels controlled. Try it in a simple click-the-target game.
